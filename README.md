# TariAgentBenchmark

Static AI poster demo for classroom use.

## Usage

Open `index.html` in a browser or visit the GitHub Pages deployment.

The app calls the 302.ai image generation API from the browser. Users enter
their own API key in the settings dialog; the key is stored only in browser
`localStorage`.

## Deploy

This repository is designed to be served directly by GitHub Pages from the
`main` branch root.
